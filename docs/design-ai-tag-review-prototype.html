Review AI tags

Jörg asked how to see, in an overview, whether the AI suggestions match the models.

What the app has today

Tags › “Suggested by AI” (top of the tag browser): one chip per suggested tag with a model count, and “Keep for all” / “Dismiss”. No pictures, so you cannot see which models a tag lands on.

Model page: suggested tags of that one model with ✓ / ✕.

Neither shows tags next to the preview across many models. This screen fills that gap.

v2 after Jörg's feedback

  • By tag is the main view. Click a suggested tag (left list) and every model it was suggested for shows up with its preview. Each card has one switch: keep the tag here or not. Switch it off on the misses, then Keep on 7, skip 2. The tag is dismissed on the skipped models, and the next tag opens.
  • Switch all on/off for tags that mostly miss. ⇧-click switches a range. A red “−2” in the list shows a tag where you already switched some off.
  • By model stays for checking single models (all suggestions of one model, keep the rest).
  • AI folders: the AI only works on folders you pick (tree with tri-state boxes, untick a subfolder to leave it out). Options: only models without own tags, run for new models after each scan, what to do without a preview. The footer shows how many models that is and about how long it takes locally.

Where you reach it

  • Sidebar › Review AI tags with the number waiting. Only while AI is set up.
  • Tags › Suggested by AI: clicking a chip opens this screen on that tag (replaces today's blind “Keep for all”).
  • Folder header: next to “Suggest tags”, “Review 34” opens it scoped to the folder.
  • Status bar when a run ends: “120 suggested · Review ›”.
  • AI folders: button on this screen, Settings › AI › Folders, and “Use for AI suggestions” in the folder menu.

Rules kept

  • Nothing is written before Keep. Every action has Undo; the “Reviewed” tab shows what was kept and dropped.
  • Library stays read-only (tags live in the index or the sidecar, as set per library).
  • Hidden entirely while AI is off, like every other AI control.

For Bob (backend needs)

  • Models with a pending suggestion for one tag, paged, filtered by folder: id, name, path, cover thumb, own tags, other suggestions, whether an image was sent.
  • Resolve one tag across models in one transaction: (tag, keep_on[], dismiss_on[]), returning what undo needs. The existing resolve_suggested_tag is the “keep on all” special case.
  • AI folder setting per library (included / excluded paths), an “after scan” hook that queues new models in those folders, and a count for the estimate.
